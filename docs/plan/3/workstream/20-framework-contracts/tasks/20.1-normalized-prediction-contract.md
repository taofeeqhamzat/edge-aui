# Task 20.1 — Normalized Prediction Contract

## Description

Define the gate-agnostic prediction result and make Fast Gate, Slow Gate, arbitration and policy
speak it.

The contract carries a predicted outcome ID (application-supplied string), confidence/match
strength, source gate, target/context reference, timestamp and prediction ID. Intervention commands
become a policy output, not a gate output.

## Acceptance criteria

- [ ] A typed `PredictionResult` (or equivalent) exists with: outcome ID, vocabulary version,
      confidence, source (`fast`/`slow`), matched flag, target/context reference, timestamp and
      prediction ID.
- [ ] `FastGate` returns a normalized prediction (or a gate result containing one), not only an
      `InterventionCommand`.
- [ ] `SlowGate` returns a normalized prediction with probabilities/confidence and source.
- [ ] Arbitration returns the selected normalized prediction and preserves provenance
      (`gate`, pattern/model version, mapping source, latency).
- [ ] The policy receives the normalized prediction plus `UIContext`; it no longer requires a gate
      to have produced an intervention.
- [ ] A testbed policy adapter maps the predicted outcome to a candidate intervention; the generic
      policy still enforces confidence/persistence/cooldown/TTL.
- [ ] The framework core does not require any specific outcome ID.
- [ ] Existing mock/ONNX gate tests either pass or are updated to the new contract with an explicit
      compatibility note.
- [ ] `npm test` and `npm run typecheck` pass.
