# Task 20.5 — Trace Schema 1.4 and Actuator Target Resolver

## Description

Add trace schema 1.4.0 and the actuator target resolver.

Trace fields (final names pending Decision 6):
- `OutcomeEvent.taskOutcome`, vocabulary version, derivation source;
- `TaskEvent.taskDefinitionVersion`, `task_fail`/extended abandonment reasons;
- `PredictionEvent.predictedOutcome`, contract version, target context;
- metadata task/semantic vocabulary version.

Actuator:
- inject a target resolver; remove the hardcoded `filter-drawer`;
- missing target fails safely with a recorded actuation failure.

## Acceptance criteria

- [ ] Schema 1.4.0 is declared, validated, recorded and exported; 1.3.0 remains readable.
- [ ] `OutcomeEvent` carries semantic outcome + vocabulary version + derivation source.
- [ ] `TaskEvent` carries task definition version and accepts `task_fail`/extended reasons.
- [ ] `PredictionEvent` carries normalized predicted outcome/contract version/target context.
- [ ] `metadata` records task/semantic vocabulary versions.
- [ ] `docs/data_schemas.md` schema index is updated; legacy 1.3.0 notes remain.
- [ ] `UIActuator` accepts a target resolver; `simplify_options` uses the configured target; a
      missing target returns a recorded failure, not a random fallback.
- [ ] Tests cover 1.4 round-trip, 1.3 compatibility, unknown version, missing fields, resolver
      success/missing target.
- [ ] `npm test` and `npm run typecheck` pass.
