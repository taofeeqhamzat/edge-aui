# Task 60.2 — Intervention Verification and Refinement

## Description

Verify every in-scope intervention type functionally and visually, refine styling/behavior where
necessary, and produce an evidence report that distinguishes visual verification from source/unit
verification.

## Acceptance criteria

- [x] `highlight_primary_action`, `simplify_options`, `expand_tooltip`, `offer_assistance` and
      `no_op` are each exercised on a real rendered target. All five are covered in
      `tests/intervention_verification.test.tsx` against `<App />`; the first four are also
      captured at 1440 × 900 in [`evidence/`](../evidence/).
- [x] For each: correct target, visible state, no layout shift that disrupts interaction, no focus
      theft, dismiss/cleanup works, no unintended DOM mutation, no duplicate episode. Report §3
      (functional) and §4–§6 (visual, geometry, focus, 0-pixel restoration).
- [x] Baseline condition applies no adaptation; adaptive condition applies only configured policy
      actions. Report §9; asserted through the composed runtime.
- [x] Missing target is tested for each applicable type; no random fallback mutation. Report §3;
      `tests/testbed_intervention_targets.test.ts` and `tests/intervention_verification.test.tsx`.
- [x] Intervention does not prevent task completion or corrupt the accessibility tree. Report §10;
      no required control is removed, the focus owner is never changed, and the tree is restored
      after a full reset.
- [x] Screenshots at the intended viewport(s) are captured for each type; a human-reviewable report
      records what was visually verified. 1440 × 900, Chrome 157, macOS; see
      [`verification-report.md`](../verification-report.md).
- [x] Refinements are limited to visibility/style/placement/dismissal; no task redesign. Report §8:
      surface marker, tooltip typography and placement, banner text, and the over-intervention
      policy fix. No page, control or task was redesigned.
- [x] The report lists visually verified vs source-only items. Report §11.
- [x] `npm test` and `npm run typecheck` pass (661 of 668; the 7 failures are the pre-existing
      `.env.local` environment failure reproduced at commit `3cec83f`).

## Verification

```bash
cd edge-aui-framework
npm test -- tests/actuator.test.ts tests/condition_trace_comparison.test.ts tests/intervention_types.test.ts
npm test -- tests/intervention_verification.test.tsx tests/testbed_intervention_targets.test.ts
npm run typecheck
```

Then run the deployed/preview testbed, trigger each configured intervention, and capture screenshots.
The captures and their interpretation are recorded in
[`verification-report.md`](../verification-report.md).

## Notes

- Do not claim an intervention is useful or improves task performance; only mechanism/visibility
  is verified here.
- `simplify_options` collapses options; verify it does not make a required task step impossible.
- TTL/dismissal behavior must be observed, not inferred from the command type.
