# Task 00.1 — Baseline Lock and Gap Register

## Description

Establish the verified starting point for the milestone. Record the repository commits, test
results, deterministic task counts and model artifact identity, then produce a gap register that
maps each remaining gap to the workstream and task that closes it.

This is a documentation/verification task. Do not change application code, configuration, models,
datasets or deployment infrastructure.

## Acceptance criteria

- [ ] `edge-aui-framework` and `model-preparation` commit hashes, branches and working-tree state
      are recorded in `docs/plan/3/workstream/00-baseline/baseline-gap-register.md`.
- [ ] The exact commands and outcomes for `npm test`, `npm run typecheck`, `npm run parity:check`
      and `python3 -m pytest tests -q` are recorded as **pass**, **fail** or **blocked**.
- [ ] The deterministic counts are re-verified from the current generator: no filters 50,
      Europe 18, Books + dateFrom 2025-06-01 5, Europe + Books + dateFrom 2025-09-01 0.
- [ ] The historical model artifacts and `bundle/v1.0.0` metadata are recorded; the five-class
      metrics are labelled historical, not semantic-head performance.
- [ ] The gap register lists: task/UI gaps, framework boundary gaps, trace/semantic gaps, model
      preparation gaps, Fast Gate gaps, intervention gaps and deployment gaps, each with the owning
      task ID.
- [ ] Any material drift from the plan is flagged; the plan is only edited where evidence requires
      it.
- [ ] No source, configuration, model, dataset or deployment file is modified.
