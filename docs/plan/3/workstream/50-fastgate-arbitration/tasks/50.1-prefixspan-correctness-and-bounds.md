# Task 50.1 — PrefixSpan Correctness and Bounds

## Description

Resolve the PrefixSpan correctness/bounds finding (Quality Assessment 2 F-02) with deterministic
tests against the WASM miner, without changing the miner boundary or introducing a second
implementation.

## Acceptance criteria

- [ ] A minimal fixture set covers: empty corpus, single sequence, repeated symbols, overlapping
      patterns, support thresholds, max pattern length, max patterns and timeout/bounds.
- [ ] The mined pattern set is deterministic and reproducible across repeated runs.
- [ ] Support and confidence are computed consistently with the declaration semantics.
- [ ] Bounded execution counters (`executed`, `skipped`, `superseded`, `timedOut`,
      `droppedWindows`) are observable and tested.
- [ ] The F-02 failing cases are reproduced before the fix and pass after it.
- [ ] No false sequence match is produced by a corpus/session boundary artifact.
- [ ] Existing miner tests and the parity check pass.
- [ ] `npm test` and `npm run typecheck` pass.
