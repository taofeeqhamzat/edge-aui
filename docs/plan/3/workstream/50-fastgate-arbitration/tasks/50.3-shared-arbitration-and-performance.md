# Task 50.3 — Shared Arbitration and Performance

## Description

Verify that both gates produce the normalized prediction contract and that arbitration selects the
prediction without testbed-specific knowledge. Measure realistic-sequence performance/memory.

## Acceptance criteria

- [ ] Fast and Slow gates return the same normalized `PredictionResult` shape (via 20.1/20.3).
- [ ] Arbitration selects Fast Gate on match, Slow Gate on miss, and returns a no-match result
      when neither produces a prediction.
- [ ] Provenance (gate, pattern, model version, mapping source, latency) survives arbitration into
      the prediction/trace.
- [ ] Policy receives the selected normalized prediction + context; it does not read DOM selectors
      or task definitions.
- [ ] Conflict/fallback behavior is documented and tested.
- [ ] Performance/memory on realistic task sequences is measured; results are reported as actual
      values, not targets.
- [ ] No regression in bounded execution or the worker boundary.
- [ ] `npm test` and `npm run typecheck` pass.

## Verification

cd edge-aui-framework
npm test -- tests/gate_arbitration.test.ts tests/worker_runtime.test.ts tests/fast_gate_bounds.test.ts
