# Task 10.4 — Reports Catalogue and Presets

## Description

Implement the approved Reports catalogue and the TD4 comparison task:

- deterministic report entries and metadata;
- `open-report-*` controls and report-row annotations;
- a current-report indicator on Analytics;
- preset filters that synchronize `currentReportId`, `appliedFilters` and the visible drawer;
- no matching row counts in the catalogue (participants must open and compare reports).

## Acceptance criteria

- [ ] Reports page renders a deterministic catalogue with at least: Europe Electronics,
      Europe Books, Europe Clothing, North America Clothing, Asia Pacific Electronics.
- [ ] Each entry has a stable report ID, display name, preset region/category, `open-report-<id>`
      control, row annotation and no matching row count text.
- [ ] Selecting a report sets `currentReportId`, applies the preset filters, updates the drawer's
      visible values, and navigates to Analytics.
- [ ] Analytics displays a visible current-report label
      (`data-aui-component="current-report"`, role `status`).
- [ ] Europe Electronics shows 3 rows; Europe Books shows 6 rows (verified deterministically).
- [ ] Opening a report does not emit a user `apply_filter`; the preset is system context.
- [ ] The Reports route is no longer a placeholder; no unrelated page content is added.
- [ ] Tests cover catalogue rendering, preset synchronization, current-report display, no counts,
      and report-open vs navigation outcome behavior (with 20.4 where available).
- [ ] `npm test` and `npm run typecheck` pass.
