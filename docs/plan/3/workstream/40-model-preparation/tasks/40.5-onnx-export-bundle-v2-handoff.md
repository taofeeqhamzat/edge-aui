# Task 40.5 — ONNX Export, Bundle v2 and Framework Handoff

## Description

Export the semantic target head and integrate it with the browser runtime through a versioned
manifest, without overwriting the previous intervention-head artifact.

**Status: executed 2026-11-20.** Bundle `v2.0.0` is committed and loaded by the framework
manifest.

## Acceptance criteria

- [x] ONNX graph inputs are `sequence_input (batch, T, 18)` and `context_input (batch, 6)`; output
      is the semantic outcome logits `(batch, 14)` — the approved target vocabulary (ADR-030).
- [x] INT8 quantization is applied; PyTorch/ONNX parity is verified within tolerance.
- [x] Model size and browser inference latency are measured; actual values are recorded, not
      targets.
- [x] `bundle.json` v2 records the target-vocabulary version and the recorded-vocabulary version,
      the dataset version/hash and split unit, code commit, seed, environment, metrics,
      input/output contract and artifact hashes.
- [x] The framework can load the new artifact through configuration/manifest; vocabulary/order is
      read from the manifest, not hardcoded.
- [x] The previous `intervention_head*.onnx` and `bundle/v1.0.0` remain untouched and reproducible.
- [x] The framework's model-version/provider reporting reflects the new artifact.
- [x] Tests cover graph contract, parity, quantization load, bundle schema/hashes and framework
      load.
- [x] `python3 -m pytest tests/test_intervention_head_export.py tests/test_reproducibility_bundle.py tests/test_semantic_head_export.py -q`
      passes (legacy suites plus the new semantic suite).

## Result (2026-11-20)

| Item | Measured value |
| --- | --- |
| Graph | `sequence_input (batch, T, 18)` + `context_input (batch, 6)` → `task_outcome_logits (batch, 14)` |
| FP32 artifact | `task_outcome_head_v2.onnx`, 189,907 B |
| INT8 artifact | `task_outcome_head_v2_int8.onnx`, 177,583 B |
| FP32/ONNX parity | max abs diff 1.9e-6 |
| INT8 parity | top-1 agreement 1.000; max logit diff 0.161 |
| CPU ORT latency | 0.04 ms avg / 0.04 ms p95 (measured in this environment; not a browser claim) |
| Bundle | `models/bundles/v2.0.0/bundle.json`; framework copy `public/models/task_outcome_head_v2.bundle.json` |
| Framework tests | 55 passed (`onnx_contract` 21, `gate_vocabulary` 16, `intervention_head_contract` 18 incl. real INT8 load) |

The <500 KB combined payload, <20 MB memory and <50 ms browser-inference targets are **not**
claimed. The INT8 graph is only ~6% smaller than FP32 because dynamic quantisation leaves the
GRU matrix multiplies largely untouched.
