# Task 40.4 — Semantic Target-Head Training and Evaluation

## Description

Train a new target head on the semantic outcome vocabulary using participant traces, while
preserving the foundation GRU and the previous five-class intervention head as reproducible
artifacts.

**Status: executed 2026-11-20** on 77 verified participant sessions. The result is
participant-derived engineering evidence; it is not a participant-held-out or user-benefit claim.
Scripted traces can still smoke-test the pipeline but do not satisfy the evaluation criteria.

## Acceptance criteria

- [x] A semantic target head has output dimension 14 — the approved target vocabulary, not the
      15-ID recorded vocabulary ([ADR-030](../../../../../decisions/ADR-030-semantic-target-vocabulary-pinned-to-14.md))
      — and accepts `(sequence, context)`.
- [x] The foundation GRU checkpoint is preserved; freeze/partial/full ablation is reproducible.
- [x] Training config records semantic taxonomy, dataset version, seed, history/horizon, class
      weights and head class count.
- [x] Evaluation reports per-class P/R/F1, support, macro-F1, weighted-F1, confusion matrix,
      majority baseline, class distribution, task-level results and held-out results at the
      declared split unit (session-held-out until a participant identifier exists;
      [ADR-031](../../../../../decisions/ADR-031-session-bounded-dataset-splits.md)).
      Participant-held-out generalisation is not claimed without an identifier.
- [x] Prediction lead time and calibration/reliability are reported where support permits.
- [x] No future data, post-intervention evidence or task-lifecycle label leaks into inputs or
      targets.
- [x] The previous five-class head/bundle remains unchanged and reproducible.
- [x] Results distinguish scripted pipeline evidence from participant-derived evaluation.
- [x] Tests cover output dimension, input contract, no-leakage assertions and metric availability.

The model exceeds the majority class on macro-F1 but is far below it on accuracy, and is
poorly calibrated. That trade-off is reported as measured; it is not a usability or
intervention-benefit claim.
