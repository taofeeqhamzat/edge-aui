# Task 70.1 — Build, Assets and Runtime Verification

## Description

Verify a clean production build, the deployment asset inventory, model/worker loading and the
baseline/adaptive runtime path after the milestone changes.

## Acceptance criteria

- [ ] `npm run build:ci` succeeds from a clean checkout with the committed WASM package.
- [ ] `npm run check:deploy-assets` passes; no asset at or above Cloudflare Pages' 25 MiB limit; no
      JSEP/WebGPU binary.
- [ ] The WASM vectoriser, ONNX Runtime WASM binary and configured model graphs are present under
      `/models/` or the expected asset paths.
- [ ] The model manifest/vocabulary version is available to the runtime; output dimension matches.
- [ ] Worker initialises and reports provider/model version; a model-load failure is visible, not a
      silent heuristic fallback.
- [ ] Baseline run applies no adaptation; adaptive run applies only configured interventions.
- [ ] Payload sizes, latency/TBT and memory are measured; actual values recorded; `NOT MEASURED`
      used where not measured.
- [ ] No historical WebGPU performance claim is reused.
- [ ] `npm test` and `npm run typecheck` pass.
