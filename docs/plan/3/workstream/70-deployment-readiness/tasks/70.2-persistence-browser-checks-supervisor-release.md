# Task 70.2 — Persistence, Browser Checks and Supervisor Release

## Description

Verify trace persistence/export, session recovery and the Supabase provenance gate in the deployed
environment; record browser/environment checks; publish the supervisor demo runbook and honest
limitations.

## Acceptance criteria

- [ ] A completed task session persists locally and exports a valid 1.4.0 trace from the deployed
      origin.
- [ ] Session recovery behaves as documented; an interrupted session is reported, not silently
      merged.
- [ ] The Supabase collection gate refuses participant-provenance upload in `scripted` mode and
      permits only the configured provenance; no service-role key is in the browser bundle.
- [ ] Baseline/adaptive runs are repeatable; trace condition/provenance/model version are correct.
- [ ] Browser/environment checks are recorded for the intended study browser; unsupported browsers
      are marked unverified.
- [ ] The supervisor demo script covers TD1–TD4, baseline/adaptive, Reports comparison, trace export
      and model/provider status.
- [ ] Known limitations, actual measurements and deferred items are documented.
- [ ] Final acceptance matrix maps each requirement to evidence (test, screenshot, trace, manual
      observation).
- [ ] No participant-study claim is made; only engineering/reproducibility evidence is reported.

## Verification

```bash
cd edge-aui-framework
npm run build:ci
npm run check:deploy-assets
node scripts/verify-trace.mjs <exported-trace.json>
```

Then run the demo script against the deployed origin and record the browser/viewport.
